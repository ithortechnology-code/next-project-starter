# Capability Map: Reusable Project Starter

| Module id            | Responsibility                                                                                                                                              | Depends on                                                                   |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `starter-apps`       | Opinionated TypeScript monorepo with Node.js API, web app, Expo app, shared package, PostgreSQL schema, and working starter flows                           | —                                                                            |
| `local-environments` | One-command setup, Compose profile selection, core/optional Docker services, health checks, and isolated agent workspaces with separate ports and databases | `starter-apps`                                                               |
| `persistence`        | PostgreSQL access through Kysely with one coordinated, append-only application migration history                                                            | `starter-apps`                                                               |
| `api-contract`       | Generated OpenAPI contract for starter and auth routes, with interactive Swagger UI                                                                         | `starter-apps`                                                               |
| `file-storage`       | Filesystem and SeaweedFS S3-compatible adapters plus bounded profile-image upload/download URLs signed by the API                                           | `local-environments`                                                         |
| `email`              | Provider-neutral SMTP mailer, Mailpit local capture, and environment-specific product SMTP configuration                                                    | `local-environments`                                                         |
| `durable-jobs`       | pg-boss producer API, separate worker process, PostgreSQL queue, and graceful shutdown                                                                      | `persistence`                                                                |
| `delivery-pipeline`  | GitHub CI, GHCR image publishing, and protected deployment to separate staging/production VPSes                                                             | `persistence`, `api-contract`, `file-storage`, `email`, `local-environments` |
| `observability`      | Correlated API request and worker job logs, bounded RED/outcome metrics, and traces shipped through an environment-local Collector to OpenObserve           | `delivery-pipeline`                                                          |

Build order: `starter-apps` → `persistence` / `api-contract` → `local-environments` → `file-storage` / `email` / `durable-jobs` → `delivery-pipeline` → `observability`. The selected starter capabilities are implemented; future product repositories add domain-specific routes, schemas, migrations, job handlers, and storage callers.
